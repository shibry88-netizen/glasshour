## 6. 动效

- **高光扫过**：7s 循环（含 2.2s 静止），扫条宽 220px、`skewX(-18deg)`、`opacity 0→0.18→0`、`cubic-bezier(.4,0,.2,1)`，只扫 T1 表层。
- **数字跳变**：旧字 `translateY(-8px)` + 淡出 180ms `cubic-bezier(.4,0,1,1)`；新字 `translateY(10px)→0` 260ms `cubic-bezier(.16,1,.3,1)`。秒位逐秒动，天位仅数值变化时动。
- **切模式**：内容交叉淡入 + 6px 纵移 320ms `cubic-bezier(.22,1,.36,1)`；胶囊滑块 240ms `cubic-bezier(.34,1.2,.64,1)`（轻微回弹）。
- **悬停**：180ms `cubic-bezier(.33,1,.68,1)`。
- **紧迫进入**：辉光 0→1，600ms ease-out，仅一次。

## 8. 反例清单（禁止）

1. 不要用纯黑 `#000` 作卡片底或阴影色 —— 一律 `#0B0C0E` 系 + 40~50% 透明黑。
2. 不要用 `#FFD700` / `#FFC107` / 亮柠檬黄冒充鎏金 —— 必须是 `#C9A45B` 系低饱和古金。
3. 不要彩虹渐变，不要金以外的第二强调色（红/蓝/绿告警色一律禁止，紧迫态只靠辉光与字重表达）。
4. 不要 >2px 的描边、不要双线边框、不要「描边+投影+发光」三件套叠加。
5. 不要 blur <12px（不够玻璃）或 >40px（糊成雾）—— T1 固定 28px。
6. 不要给玻璃叠饱和度 >150% 的底色 tint，玻璃会显脏 —— `saturate` 上限 140%。
7. 不要装饰性元素：点阵、星芒、几何碎片、卡通插画、emoji 图标。
8. 不要 <12px 字号；不要比例数字（必须 `tabular-nums`），否则秒位抖动。
9. 不要金色大面积色块 >30% 卡片面积 —— 金只用于数字、描边、按钮、图标。
10. 不要 16px 图标保留渐变/高光/透明度 —— 小尺寸必须单色实心。
11. 不要圆角 >24px 的按钮，圆角风格要统一（胶囊 = 半高，卡片 = 20px）。
12. 不要在玻璃上直接压高对比图片纹理；噪点 opacity 上限 0.04。

## 9. 待真机验证（设计师明确标注）

- Windows 10 上 `backdrop-filter` 在 Electron 的 **WorkerW 子窗口**里是否稳定出效；若失效 → 降级为「快照壁纸 + 高斯模糊贴图」方案，届时 blur 值需重测。
- `Segoe UI Variable Display` 在 Win10 旧版可能缺失，回退链已覆盖。

# 增量规范 v1.1（多条目 / 备注 / 条目管理）

> 出处：同一设计师 agent 的增量产出。**旧规范的画布、色板、字体、玻璃三档、五种状态、既有坐标全部沿用不动**，本节只写新增部分。

## 10. 备注行（note） · A 模式

- 位置 **X20 Y240 W380 H20**，单行、垂直居中、水平居中。
- 字号 **12** / 字重 **400** / 字距 **0.04em** / 文字·次 `rgba(236,232,224,.55)`。
- 与副行关系：副行 Y214 H22（底 236）→ 4px 间隔 → 备注（240–260），恰好落在安全边距底缘 260。层级顺序：主数字 > 副行 > 备注。
- 选 .55 而不是 .34：备注是用户自己写的内容，必须可读。
- **超长截断**：单行、尾部 `…`，绝不两行、绝不跑马灯、绝不自动缩字号。硬上限以**渲染宽 340px** 为准（盒宽仍 380 居中，左右各留 20px 呼吸）。
- **为空**：整行**不渲染**（`display:none`），其它元素坐标**零位移** —— 切换有/无备注的条目时卡片不得跳动。禁止用「暂无备注」、虚线、图标补洞。
- **状态联动**：五态中备注的位置/字号/字重/字距/色阶**全部不变**；仅暂停态随卡片整体 saturate 降低。
- **B 计时模式不显示**：按钮占 Y208–246，安全底缘 260，剩余仅 14px，放字会贴死按钮。

## 11. 多条目切换控件（≥2 条才出现）

- 形态：**T2 玻璃胶囊 + 左右箭头 + 「当前 / 总数」计数器**。
  （不用下拉：会遮主数字，且 WorkerW 子窗口的弹层点击不可靠；不用小圆点：超 5 条失效且属装饰性元素。）
- **X196 Y28 W96 H28 r14**，与左上模式胶囊同高同圆角，形成顶栏三件套节奏。
- 位置取顶栏空档（模式胶囊右缘 124 → 齿轮左缘 364）的正中：左右各留 72px。
- 内部：`‹` 28×28｜计数器区 40px｜`›` 28×28。箭头为 6×10 线性三角，描边 1.5px。
- 计数器：数字链，字号 **12**；当前数字字重 **600 + 文字·主**，`/` 与总数字重 400 + 文字·弱 `.34`。形如 `3 / 5`。
- 状态：默认箭头 `.55`；胶囊 hover → 白 6% overlay，箭头升 `.92`；单个箭头 hover → 该 28×28 槽白 8%；按下白 10%，无位移。
- **边界禁用**：第 1 条时 `‹`、最后一条时 `›` 变 `.20`、不可点、无 hover（**不循环**，方向可预期）。
- **切换动效**：仅主数字 / 事件标签 / 副行 / 备注做 **120ms crossfade**，控件、胶囊、齿轮、按钮**一律不动**。
- **1 条时完全不渲染**：不留槽位、不留 disabled 灰控件、不预留空位。
- 超过 5 条：形态不变，计数器自然扩展（`7 / 12`）。≥10 条不缩字号；实测 `12 / 12` 仍在 40px 内 → 胶囊宽度 **96px** 不变（真机渲染实测通过）。

## 13. 超长条目名称截断（事件标签 X20 Y84 W380 H18）

单行居中，**不换行、不缩字号、不减字距（恒 0.18em）、不做中部省略**。截断阈值 **340px 渲染宽**（≈ 22 个全角字符 @13px+0.18em）。设置端名称 maxlength 20，340px 是兜底。

## 14. v1.1 新增反例

1. 不要用下拉菜单 / 弹出层做条目切换 —— 遮挡主数字，且 WorkerW 子窗口的弹层点击不可靠。
2. 不要用小圆点 / 进度点做条目指示 —— 超 5 条失效，且属装饰性元素。
3. 不要把多条目做成顶部横排 tab（名称直接当 tab 文案）—— 名称宽度不定，必然挤爆顶栏。
4. 不要用红 / 橙 / 绿表示「已过期」「删除」「备注超长」「输入满额」—— 禁第二强调色，一律靠 .55/.34 与禁用态表达。
5. 不要把备注做成两行、跑马灯、自动缩字号或滚动播放。
6. 不要在备注为空时放占位文字、虚线、图标或分割线「补洞」。
7. 不要在只有 1 条时渲染切换控件（哪怕 disabled），也不要切换条目时让任何元素位移。
8. 不要给名称 / 备注加彩色标签胶囊、底色块、>2px 描边；切换控件不得用金色填充。

## 15. 实现侧补充（非设计师产出，工程记录）

- 切换控件做成 **`left:244px + translateX(-50%)` + `min-width:96px`**，条目数变多时胶囊自动加宽而**不缩字号**，且始终保持在 124–364 空档正中。
- 时间统一用**本地朴素串** `YYYY-MM-DDTHH:mm:ss` 存储（`new Date(str)` 按本地时区解析），消除设置页 `datetime-local` 的时区偏移。
- 版面正确性由 `scripts/layout_audit.js` 做机器断言（量几何盒，比**墨迹**而非行框，避免行高留白造成的假重叠）。
