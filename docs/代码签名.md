# GlassHour · 代码签名说明

> 结论先讲：**本项目的 exe 目前是未签名的。** 不是忘了签，而是「可信签名证书」拿不到 —— 下面说清为什么、以及你能怎么拿到。

## 1. 为什么没签

Windows 的 SmartScreen 只认**由受信任 CA 签发**的代码签名证书。三条现实路径：

| 方案 | 成本 | 门槛 | 对 SmartScreen |
| :-- | :-- | :-- | :-- |
| **自签名证书** | 免费 | 无 | ❌ **完全没用** —— 根证书不受信任，仍然报「未知发布者」，警告甚至更重 |
| **OV 代码签名证书** | ~$100–300/年 | 需要**实名/企业身份核验** | 需要累积信誉，新证书初期仍会被拦 |
| **EV 代码签名证书** | ~$300–500/年 | 需要**注册企业实体**（个人基本拿不到）+ 硬件令牌 | ✅ 立刻取得信誉 |

**关键点**：不是技术问题，是**身份核验**问题 —— 必须由真人拿着身份证件去 CA 走一遍验证。我作为 agent 办不到，所以没法替你签。

## 2. 你这个项目能走的免费/低价路线

### ⭐ 首选：SignPath Foundation（开源项目免费签名）

<https://signpath.org/> —— 专门给**开源项目**免费签发代码签名证书（SignPath.io 赞助）。

- 要求：公开仓库 + MIT/Apache 这类 OSI 许可 + 有一定活跃度 → **GlassHour 完全符合**
- 流程：官网提交申请 → 人工审核（几天到几周）→ 拿到证书后走他们的 CI 集成签名
- 拿到之后，本项目的构建脚本可以接上（见下）

### 备选：Certum 开源代码签名证书

<https://shop.certum.eu/open-source-code-signing-on-simplysign.html> —— 约 **$49**，针对开源项目，比标准 OV 便宜很多，但需要身份核验。

### 备选：OSSign

另一个给开源项目提供免费签名的服务，门槛比 SignPath 宽松一些，可对比申请。

## 3. 拿到证书后怎么接进来（本仓库已预留）

`electron-builder` 原生支持 `CSC_LINK` / `CSC_KEY_PASSWORD` 两个环境变量，**不需要改一行代码**：

```bash
# 证书是 .pfx / .p12 文件
export CSC_LINK=/path/to/cert.pfx
export CSC_KEY_PASSWORD='证书密码'
bash tools/build_vps.sh 1.2.0

# 或者直接把证书做 base64 塞进环境变量（适合 CI）
export CSC_LINK="$(base64 -w0 cert.pfx)"
export CSC_KEY_PASSWORD='证书密码'
bash tools/build_vps.sh 1.2.0
```

`tools/build_vps.sh` 会检测这两个变量并在日志里明确告诉你「这次签了没有」。

> ⚠️ **证书文件绝对不要提交进仓库**。`.gitignore` 已经挡了 `*.pfx` / `*.p12` / `*.key`；
> 真要放仓库也只能放加密后的密文（本项目在别处就是这么管理构建机私钥的）。

## 4. 怎么验证签没签上

```bash
# Windows 上
signtool verify /pa /v GlassHour-Setup-1.2.0.exe
# 或右键 exe → 属性 → 数字签名

# Linux 上（需要 osslsigncode）
osslsigncode verify GlassHour-Setup-1.2.0.exe
```

## 5. 自签名演示（仅供验证签名流程，不要发给别人）

想先确认「签名这条链路在本项目里能跑通」，可以用自签名证书试一次：

```bash
# 1) 生成自签名代码签名证书（Linux 上，需要 openssl）
openssl req -x509 -newkey rsa:3072 -keyout key.pem -out cert.pem -days 1095 -nodes \
  -subj "/CN=GlassHour Dev/C=CN" \
  -addext "keyUsage=digitalSignature" \
  -addext "extendedKeyUsage=codeSigning"

# 2) 打包成 pfx
openssl pkcs12 -export -out selfsign.pfx -inkey key.pem -in cert.pem -passout pass:test

# 3) 用 electron-builder 签名打包
export CSC_LINK=$PWD/selfsign.pfx
export CSC_KEY_PASSWORD=test
bash tools/build_vps.sh 1.2.0
```

产物在「属性 → 数字签名」里能看到签名信息，但**发布者仍然显示为未验证**、SmartScreen 照样拦 —— 所以**别把自签名的包当正式版发出去**。

## 6. 用户侧临时绕过

在拿到正式证书之前，用户第一次运行会被 SmartScreen 拦：

> 「Windows 已保护你的电脑」→ 点 **更多信息** → **仍要运行**

这是未签名软件的必然待遇，不是包坏了。
