# GlassHour · 构建与部署

> 本文记录 **在 Linux 构建机上交叉打出 Windows 包** 的完整流程，以及踩过的坑。照抄可用。

## 0. 一句话

Lobe 云沙盒**不是构建机**（随时重置、无 ssh/wine、磁盘仅 8G），它只当"上传源码 + 驱动远程构建 + 取回产物"的跳板。
真正的构建在自购 VPS 上做。

## 1. 构建机

| 项 | 值 |
| :-- | :-- |
| 主机 | `cn-fj-qz-3.server.zakocloud.com` |
| SSH 端口 | **30061**（NAT 映射，不是 22） |
| 用户 / 系统 | `root` · Debian 12 (bookworm) |
| 规格 | 4 核 / 7.9 GB / 30 GB |
| 登录 | SSH 私钥（密文存 `keystore/vps_key.enc`，外层口令单独保管） |

```bash
# 沙盒重置后的恢复姿势
apt-get update -qq && apt-get install -y -qq --no-install-recommends openssh-client
mkdir -p ~/.ssh
openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 \
  -in keystore/vps_key.enc -out ~/.ssh/vps_key -pass pass:'<外层口令>'
chmod 600 ~/.ssh/vps_key
SSHOPT="-i ~/.ssh/vps_key -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null"
ssh $SSHOPT -p 30061 root@cn-fj-qz-3.server.zakocloud.com 'echo OK'
```

## 2. 构建机上的一次性工具链

```bash
dpkg --add-architecture i386 && apt-get update -qq
apt-get install -y --no-install-recommends git curl unzip xz-utils ca-certificates build-essential python3
apt-get install -y --no-install-recommends wine wine64 wine32   # electron-builder 打 Windows 包需要
curl -fsSL https://deb.nodesource.com/setup_20.x | bash - && apt-get install -y nodejs
npm i -g playwright && npx playwright install --with-deps chromium   # 截图用
```

装完的实际版本（2026-10-13 实测）：**wine 8.0 · Node 20.20 · Chromium 1148**。

## 3. 出包

```bash
# 1) 把源码送到构建机（本项目 git 协议到 GitHub 不通，用 scp）
tar czf /tmp/gh.tgz --exclude=node_modules --exclude=dist --exclude=.git glasshour
scp $SSHOPT -P 30061 /tmp/gh.tgz root@$HOST:/opt/gh.tgz
ssh $SSHOPT -p 30061 root@$HOST 'rm -rf /opt/glasshour && mkdir -p /opt/glasshour &&
  tar xzf /opt/gh.tgz -C /opt/glasshour --strip-components=1'

# 2) 装依赖 + 打包（长任务必须后台跑，见坑 #3）
ssh $SSHOPT -p 30061 root@$HOST 'cd /opt/glasshour &&
  ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ \
  ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/ \
  setsid nohup npm install --no-audit --no-fund > /root/npm_install.log 2>&1 < /dev/null &'

# 3) 打包
ssh $SSHOPT -p 30061 root@$HOST 'cd /opt/glasshour && bash tools/build_vps.sh <版本号>'

# 4) 取回产物
scp $SSHOPT -P 30061 root@$HOST:/opt/glasshour/dist/GlassHour-Setup-*.exe /tmp/
```

产物：

- `GlassHour-Setup-<版本>.exe` —— NSIS 安装向导
- `GlassHour-Portable-<版本>.exe` —— 免安装绿色版

## 4. 截图（打包前确认用）

液态玻璃的模糊/折射**必须有背景才成立**，所以截图必须先垫一张模拟壁纸：

```bash
python3 scripts/make_wallpaper.py     # 生成 design/mock/wallpaper.png (1920x1080)
node scripts/render_icon.js           # assets/icon.svg → design/icon-1024.png
python3 scripts/make_icons.py         # → build/icon.ico + 多尺寸 + design/icon-sheet.png
node scripts/screenshot.js            # → design/shots/*.png（垫着壁纸的真渲染）
```

`scripts/screenshot.js` 用 Playwright 打开 `renderer/index.html`，并通过 `window.__GH_MOCK__`
注入状态（默认/悬停/紧迫/归零/计时中/暂停），所以**不启动 Electron 也能出真 UI 截图**。

## 5. 踩坑清单（本项目实录）

1. **`editFile` 回报不可靠** —— 它可能报告"替换 0 处"但**其实已经改了**（本次因此产生重复的 IPC handler）。
   → 改代码一律用 python 脚本 + `assert s.count(old) == 1` 精确替换，再用 `node --check` 复核语法。
2. **构建机到 GitHub 的 git 协议不通** —— `git clone` 卡住、`git ls-remote` 超时（`curl https://github.com` 却是 200）。
   → 源码用 `scp` 送过去；仓库仍是唯一真源，本地副本与仓库保持同步。
3. **命令网关约 60 秒超时** —— 任何超过 1 分钟的命令（npm install、apt 大包、Playwright 装浏览器）都会
   `Gateway Timeout`。
   → 一律 `setsid nohup <cmd> > log 2>&1 < /dev/null &` 后台化，再单独轮询日志。
4. **Linux 打 Windows 包需要 wine** —— `electron-builder --win` 在 Linux 上要用 wine 跑 rcedit/NSIS。
   不装 wine 就只能出 `--dir` 且 exe 没有图标。
5. **原生模块要用 N-API** —— `koffi` 是 N-API，Linux 上装的包内含 win32-x64 预编译产物，交叉打包不用重编；
   但要在 `build.asarUnpack` 里排除它，否则 `.node` 被塞进 asar 加载失败。
6. **液态玻璃截图不能透明底** —— `omitBackground: true` 会让 `backdrop-filter` 无物可模糊，出来的玻璃是死的。
7. **组件窗口的阴影要留白** —— 卡片 420×280，窗口开 460×320，四周各留 20px 给投影，否则阴影被裁。
8. **`WorkerW` 不一定找得到** —— 多显示器 / 第三方桌面美化 / Explorer 被替换时会失败，
   必须有"不可激活底层窗口"的回退路径，并在托盘给用户手动切换的口子。
